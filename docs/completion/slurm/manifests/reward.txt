# WHAT CHANGED UNDERNEATH (2026-09-14). --reward-objective score is now the
# default and is passed explicitly below anyway:
#   - terminal reward = the participant score humans were given (SCORE_STUDY_V1):
#     best progress on a loss in [0,1), 1 + 0.5 * hideout_uncertainty on a win.
#     --reward-gamma 0.5 is part of the objective, inherited, never varied here.
#   - alpha/beta/zeta = exact potential-based shaping, F = w(gamma*Phi(s') - Phi(s)),
#     Phi(terminal) = 0. They can change learning speed, not the optimum.
#   - delta = decaying count-based exploration bonus, unchanged from before.
# Every earlier wave trained on --reward-objective legacy (+/-1 terminal).
#
# DESIGN: 3 nested reward conditions x 2 curriculum conditions x 3 seeds.
#
#               | curriculum (max-difficulty 0) | no curriculum
#   obj         | w10-obj-cur                   | w10-obj-off     objective only
#   dlt         | w10-dlt-cur                   | w10-dlt-off     + delta
#   shp         | w10-shp-cur                   | w10-shp-off     + delta + alpha/beta/zeta
#
# Adjacent rows isolate one thing each:
#   obj -> dlt   the exploration bonus. Judge on FINAL score (last-5 eval) and
#                explore/coverage — delta is not potential-based, and the claim
#                under test is that it raises final score via map coverage.
#   dlt -> shp   the shaping. Judge on SAMPLE EFFICIENCY (steps to 80%/90% of
#                final score, area under the eval score curve). Exact
#                potential-based shaping cannot change the optimum, so a final-
#                score difference here means a bug, not a finding.
# cur vs off, in each row: the curriculum under the true objective — this also
# re-runs 04's Director comparison, and supplies 06's checkpoints.
#
# Seeds 41/42/43: fresh, independent of 04 (31-33) and the tuning waves (27-29).
# Rank on eval/score (Director-free), never charts/* on a curriculum run.

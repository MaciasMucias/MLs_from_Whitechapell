# Director v3 — closing the two gaps in the 09 conclusion. 18 tasks, --array=0-17%9
#
#   sbatch --array=0-17%9 docs/completion/slurm/array.sbatch \
#          docs/completion/slurm/manifests/director_v3.txt
#
# ### WHY ###
#
# The branch wave (1807209) showed every Director configuration it tested losing
# to no-Director, at all 69 evaluation points, never once ahead. But it tested
# only 2 of the Director's knobs in a regime where the controller was live, and
# it has a structural confound. Two gaps:
#
#   A. EVERY branch arm carries a 4.4-4.9M-step prefix trained at difficulty
#      -1.0. So "dbr-off" is really "suppressed prefix, then no Director" — the
#      Director as DESIGNED (on from step 0, ramping naturally, as in the
#      historic mdw4ndpi run) has never been run against a from-scratch OFF.
#
#   B. --curriculum-kp, --curriculum-max-step and --curriculum-ratchet were only
#      ever swept in wave 1807070, which is void: the curriculum never engaged
#      there, so those knobs were untested rather than disproven. Both valid
#      adaptive arms used the default kp=0.1.
#
# ### THE PREDICTION THIS TESTS ###
#
# The fixed-difficulty dose-response is monotone (-1.0 -> 50.7%, -0.5 -> 88.3%,
# none -> 93.2%). If less suppression is monotonically better, then any
# controller spending time at negative difficulty is worse than one that does
# not: SLOW kp means more time suppressed and should be WORSE, fast kp should be
# better, and the limit of infinitely-fast kp is exactly no Director.
#
# So the prediction is: kp-002 < kp-010 < kp-030 < off. If that ordering does NOT
# hold, the monotone story is wrong and there is a curriculum effect worth
# chasing. That is the outcome to watch for — this wave is designed to be able to
# falsify the conclusion, not to confirm it.
#
# Caveat kept in view: the dose-response SATURATES near zero (-1.0->-0.5 gains
# 37.6 points, -0.5->0.0 only 4.9). A shallow peak just below zero would be
# invisible at three sample points. That is gap C, not covered here — a finer
# fixed grid (-0.25, -0.1, +0.1) would be the follow-up if this wave's ordering
# holds but the margin to `off` stays small.

# Workstream 10 — second seed top-up: the shaping arms, 6 -> 9 seeds. 6 tasks.
#
#   sbatch --array=0-5%6 docs/completion/slurm/array.sbatch \
#          docs/completion/slurm/manifests/seeds_topup2.txt
#
# WHY. At 6 seeds the curriculum effect is +0.120 (objective only), +0.143
# (+delta) and +0.093 (+delta+shaping), against a 0.083 threshold. The first two
# clear by 43% and 72%; the shaping condition clears by **12%**.
#
# That is the same margin the retracted substitution claim had (14%, Appendix
# A.2), and it carries the robustness statement "the curriculum helps in every
# reward condition". If this arm drifted the way shp-off did when it went 3 -> 6
# seeds, the claim would collapse into "helps when shaping is absent" - which is
# the retracted interaction story returning, and a second reversal of the same
# result.
#
# 3 more seeds on each shaping arm takes them to 9 and the threshold to 0.068,
# so +0.093 would clear by 37%.
#
# NOT included, deliberately:
#   the other four arms - obj and dlt clear comfortably at 6 seeds. Taking every
#     arm to 9 would tighten the NULLS (0.083 -> 0.068) but the thesis does not
#     need to exclude a +0.07 shaping effect it already reports as absent.
#   04's Director arms - still 3 seeds and unresolvable there, but under the
#     superseded legacy reward; the Director claim rests on this wave.
#
# Seeds 71/72/73: fresh, independent of 41-43, 51-53, 61-63 (this wave's
# earlier triples), 31-33 (04) and 27-29 (the tuning waves). Flags are identical
# to the corresponding wave 10 lines - only the seed differs.
#
# Pool all nine seeds per arm when reading; the export prefix is reward_topup2.

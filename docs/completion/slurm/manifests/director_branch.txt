# points are the first checkpoint at or after training win rate sustained > 0.60
# for 20 consecutive updates — where the P-controller would first have hardened.
# Computed by tools/branch_point.py:
#
#   dbase-s27  sustained from step 4,380,672  ->  agent_0004454400.pt
#   dbase-s28  sustained from step 4,420,608  ->  agent_0004454400.pt
#   dbase-s29  sustained from step 4,780,032  ->  agent_0004915200.pt
#
# All three crossed within ~400k steps of each other, so the arms stay
# comparable across seeds. Note this is 4.4-4.8M — every run in 03 and in 09
# stopped at 3M, i.e. before any of these points.
#
# "Sustained", not first-crossing, deliberately: 09's runs each touched above
# the band exactly once, on the final update, which was enough to make the wave
# look engaged when it was not.
#
#   sbatch --array=0-14%9 docs/completion/slurm/array.sbatch \
#          docs/completion/slurm/manifests/director_branch.txt
#
# ### WHAT THIS IS ###
#
# The comparison workstream 09 was meant to be, now run in the regime where the
# controller is actually live. 09 ran entirely BEFORE the first difficulty
# uptick, so its Director settings could not matter and six configs produced
# byte-identical policies.
#
# Five arms x three base checkpoints. Every arm branches from the SAME policy,
# so between-arm differences are attributable to the Director rather than to
# initialisation — which is a cleaner contrast than 09's independent runs, where
# a ~9.5-point seed noise floor swamped everything.
#
# --branch-from (not --resume) is required: --resume would force the base's
# saved curriculum difficulty onto every arm, rejoin the base's single W&B run
# from all 15 tasks, and carry over its best-eval tracker.
#
# ### THE ARMS ###
#
#   fix10   difficulty pinned at -1.0 — the control. No curriculum at all.
#   fix05   difficulty pinned at -0.5 — 09's one real signal was that the FIXED
#           suppression level moves results (-0.5 -> 37.0%, -1.0 -> 35.0%,
#           off -> 27.0%, all n=1). This tests it with seeds.
#   b4060   adaptive, the original [0.40, 0.60] band.
#   b2035   adaptive, band lowered INTO the achievable range. Training win rate
#           under full suppression sits around 0.40-0.60, so the original band
#           is mostly satisfied or below; a lower band gives the controller a
#           reason to HARDEN rather than only ever ask for easier.
#   off     no Director.
#
# ### READING IT ###
#
# Check off_floor% BEFORE the ranking. If b2035 and b4060 are still pinned even
# post-uptick, re-banding cannot rescue the curriculum and that is the finding.
# Rank on Director-free eval/win_rate; charts/win_rate is the controller's
# setpoint for ON arms, not a score.

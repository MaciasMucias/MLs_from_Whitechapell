# WHAT THIS WAVE DECIDES
#   The PPO core: --lr x --ent-coef, 3x3, run on BOTH Director arms.
#   Sweeping both arms is what removes 03's fairness caveat — tuning only with
#   the curriculum ON and reusing that config for the OFF arm mildly favours ON.
#   18 tasks is under the 20-job MaxSubmitJobs cap; %9 respects the 72-CPU cap.
#
# COST
#   3M steps at ~682 SPS = ~1.2h per task; 18 tasks / 9 concurrent = ~2.5h wall.
#
# FIXED ACROSS EVERY LINE (and carried unchanged into wave 2 and 04)
#   --n-envs 12 --n-workers 12   batch = n_steps * n_envs = 256 * 12 = 3,072
#   --seed 27                    one seed here; the 3-seed replication is 04's job
#   cops frozen at COPS_STUDY_V2 (01), which is HeuristicCops()'s default
#
# READING THE RESULT
#   Primary   eval/win_rate.  Secondary  eval/mean_hideout_uncert — a policy that
#   wins by luck rather than by staying unpredictable scores low on it.
#   Compare arms only within an arm; ON runs face suppressed-knowledge cops and
#   will show a higher win rate for reasons that are not policy quality.
#

# Workstream 12 — does the curriculum effect survive convergence? 12 tasks.
#
#   sbatch --time=23:55:00 --array=0-11%9 docs/completion/slurm/array.sbatch \
#          docs/completion/slurm/manifests/convergence.txt
#
# --time overrides array.sbatch's 23:00:00. 40M steps at the slowest SPS seen on
# this cluster (~575) is ~19.3h; the extra hour is margin, and 24h is the cap.
#
# WHY. Every result in the thesis is "at 15M steps", and the score was still
# rising in every wave-10 arm when the budget ran out (tail slopes +0.022 to
# +0.041 per 1M). train.py anneals the learning rate LINEARLY TO ZERO over
# --total-steps, so 15M is where the schedule stopped the runs, not where they
# plateaued. That leaves the headline ambiguous between two readings:
#
#   the gap persists  -> the curriculum produces a better FINAL policy
#   the gap closes    -> the curriculum is a SAMPLE-EFFICIENCY method: the same
#                        destination, reached ~36% faster
#
# Both are findings. At 15M the thesis cannot say which.
#
# DESIGN. obj-cur vs obj-off - the recommended arm and its matched control -
# from scratch at 40M (2.7x the budget), flags otherwise identical to wave 10.
# From scratch, not resumed: resuming a 15M run would restart a learning-rate
# schedule that had already reached zero, which is not what a 40M run is.
#
# 6 fresh seeds per arm (81-86). If the gap SHRINKS, 3 seeds (threshold ~0.111)
# could not tell "closed" from "smaller"; 6 (threshold ~0.079) can bound it.
# Seeds 81-86 are independent of every earlier wave (27-29, 31-33, 41-43, 51-53,
# 61-63, 71-73).
#
# HOW TO READ IT (decided before the data): docs/completion/12-convergence.md.
